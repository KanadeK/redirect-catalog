# Security

Version 0.1.x receives best-effort fixes. Report vulnerabilities privately at
https://github.com/KanadeK/redirect-catalog/security/advisories/new
when private reporting is enabled. If unavailable, open an issue requesting a
private contact without exploit details or private data.

The tool reads local files, makes no network calls and does not execute input.
Documented budgets are not an OS sandbox. Use closed copies of inputs and
ordinary user permissions.
